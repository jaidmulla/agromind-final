# 🔄 How to Save Changes and Make Them Persist

## Problem You Had
✗ Made code changes in AI Doctor  
✗ Closed VS Code, Docker, everything  
✗ Next day: Old project shows, changes gone  

## Solution: The Rebuild Process

The key is: **Code changes must be built into Docker images to persist.**

---

## Method 1: Quick Rebuild (Recommended for Daily Dev) ⚡

### Step 1: Make Your Code Changes
```bash
# Edit files in VS Code normally
# Example: src/services/local-ai-doctor.service.ts
```

### Step 2: Run the Rebuild Script
```bash
chmod +x rebuild.sh
./rebuild.sh
```

**What it does:**
1. ✅ Stops all running containers
2. ✅ Cleans old build files
3. ✅ Rebuilds backend (TypeScript → JavaScript)
4. ✅ Rebuilds frontend (React/Vite build)
5. ✅ Rebuilds Docker images with your latest code
6. ✅ Starts everything fresh

**Result:** Changes are now permanently saved in Docker images

---

## Method 2: Manual Rebuild Steps

If the script doesn't work, do this manually:

### Step 1: Stop Everything
```bash
docker-compose down
```

### Step 2: Build Backend
```bash
cd backend
npm run build
cd ..
```

### Step 3: Build Frontend
```bash
cd frontend
npm run build
cd ..
```

### Step 4: Rebuild and Start Docker
```bash
docker-compose up --build -d
```

### Step 5: Wait for Services
```bash
sleep 10
docker ps
```

---

## Method 3: Development Mode (See Changes Instantly)

For when you want live code reload without rebuilding:

```bash
# First build once
docker-compose up --build -d

# Then use dev override for hot-reload
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

**Note:** This mounts source code directly, so changes apply instantly  
**Warning:** On restart next day, you'll need fresh builds

## Verification: Code Changes Persisted ✅

After running `rebuild.sh` or manual rebuild:

### Check 1: Docker Images Have Latest Code
```bash
docker images | grep agromind
```
You should see recent build timestamps

### Check 2: Verify in Browser
Open http://localhost:3000/chat
- Changes you made should appear
- Test your specific feature works

### Check 3: Verify Code in Container
```bash
# See the code running inside container
docker exec agromind-backend cat /app/dist/services/local-ai-doctor.service.js | grep -i "crop_specific"
```

## Complete Daily Workflow 📋

### Morning (First Start of Day)
```bash
# Restart with latest code
docker-compose down
docker-compose up --build -d

# Wait for health checks
sleep 10
docker ps
```

### During Development (Making Changes)
```bash
# Edit code in VS Code
# Changes saved to source files automatically ✅

# Option A: Quick rebuild (few seconds)
./rebuild.sh

# Option B: Full rebuild (few minutes)
docker-compose down
docker-compose up --build -d
```

### Evening (Before Closing Day)
```bash
# Make sure latest code is built into Docker
./rebuild.sh

# Check health
docker ps

# Now safe to close VS Code/Docker for the day!
# Everything is persisted in Docker images ✅
```

### Next Day at Work
```bash
# All your changes are still there!
docker-compose down
docker-compose up -d

# Your code changes persist! 🎉
```

## Where Code Gets Saved 💾

### 1. **Source Files** (These are where your edits go)
```
backend/src/services/local-ai-doctor.service.ts  ← Your edits here
frontend/src/app/pages/AIDoctorChat.tsx          ← Your edits here
```
✅ Saved to disk immediately when you edit  
✅ Survives VS Code close  
✅ Survives computer restart  

### 2. **Built Files** (Compiled versions)
```
backend/dist/services/local-ai-doctor.service.js  ← Generated by npm run build
frontend/dist/                                     ← Generated by npm run build
```
⚠️ Only created when you run `npm run build`  
⚠️ Must exist for Docker to include in image  

### 3. **Docker Images** (The packaged app)
```bash
docker images | grep agromind-backend
```
🐳 Created by `docker-compose up --build`  
🐳 Stores the compiled code + all dependencies  
🐳 **This is what you run next day!**  

### 4. **Running Containers** (Live app)
```bash
docker ps | grep agromind
```
▶️ Started from the Docker image  
▶️ What users interact with

## Why Changes Disappeared Before ❌

**Old Flow (Broken):**
```
Edit code in VS Code
  ↓
Change stays in vs code editor only
  ↓
Docker containers still running old code
  ↓
You close VS Code (changes not saved to disk properly)
  ↓
Next day: Docker images still have OLD code
  ↓
❌ Changes lost!
```

**New Flow (Fixed):**
```
Edit code in VS Code
  ↓
Code saved to disk (/backend/src/*.ts)
  ↓
Run ./rebuild.sh
  ↓
  1. NPM builds to /backend/dist/ ✅
  2. Docker image created with /dist/ files ✅
  3. Containers started from new image ✅
  ↓
Close VS Code, shut down Docker
  ↓
Next day: Docker image still has NEW code
  ↓
✅ Changes persist!
```

## Troubleshooting 🔧

### Problem: Changes still not showing
**Solution:**
```bash
# Force clean rebuild
docker-compose down
docker system prune -f
./rebuild.sh
```

### Problem: "I forgot to rebuild"
**Solution (requires OpenAI API):**
```bash
# Just rebuild now, it will catch up
./rebuild.sh

# If you had critical changes, remember:
# - Browser cache might show old version
# - Force refresh: Ctrl+Shift+R (Chrome) or Cmd+Shift+R (Mac)
```

### Problem: Want to keep changes from yesterday
**Solution:**
```bash
# Before starting work
git status  # See what changed
git diff    # Review changes

# If good, commit them
git add -A
git commit -m "AI Doctor improvements: crop-specific plans"

# Then rebuild fresh
./rebuild.sh

# Your changes are now in git AND Docker ✅
```
